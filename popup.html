    Look up NetSuite records from any webpage — highlight, right-click, done.

    How it works PROD
    1. Highlight text on any page — a sales order number, item, RMA, or keyword.
    2. Right-click and choose Search [Environment] Record.
    3. Pick a record type — results open in a new NetSuite tab.

    Record types: Quick Search (global) · Sales Order · Purchase Order · Transfer Order · Item · Return.

    Connection
    It's the subdomain of your NetSuite URL: https://<account-id>.app.netsuite.com. Required before search will work.
    The badge in "How it works" above and the toolbar icon always show the current target, so a sandbox search can't sneak into Production.
    Recommended NetSuite setting

    Turn off Show List When Only One Result so a single match opens the record directly instead of a one-row list. (show me where)
